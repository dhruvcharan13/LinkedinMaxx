# LinkedInMaxx Backend

Python backend for LinkedInMaxx automation using LangChain agents and Redis queues.

## Quick Start

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Configure environment:**
   ```bash
   cp .env.example .env
   # Edit .env with your OpenAI API key and Redis settings
   ```

3. **Start Redis:**
   ```bash
   docker run -d -p 6379:6379 redis:alpine
   ```

4. **Test the setup:**
   ```bash
   python test_agents.py
   ```

5. **Start the server:**
   ```bash
   python main.py
   ```

## Architecture

- **Agents**: LangChain agents for post generation, messaging, and dating
- **Redis**: Task queues and agent memory
- **FastAPI**: REST API for frontend communication
- **Playwright Integration**: Publishes instructions to Redis for Playwright to consume

## Key Features

- 🤖 **Daily Post Agent** - Generates LinkedIn posts using AI
- 💬 **Messaging Agent** - Classifies profiles and generates messages
- 💕 **Dating Agent** - Detects Waterloo students and generates pickup lines
- 📤 **Instruction Publishing** - Publishes instructions to Redis for Playwright
- 🎨 **Rich Terminal Output** - Beautiful colored terminal feedback

## API Endpoints

- `GET /health` - Health check
- `POST /api/start-scrolling` - Start automation workflow
- `POST /api/stop-scrolling` - Stop automation workflow
- `POST /api/generate-daily-post` - Generate and queue a post
- `POST /api/process-profile` - Process a single profile
- `GET /api/queue-stats` - Get queue statistics

## Workflow

1. **Daily Post** → Generated by agent → Published to `playwright:post` queue
2. **Profile Scraping** → Playwright scrapes → Publishes to `profiles:scraped` queue
3. **Profile Processing** → Messaging Agent classifies → Routes to Dating Agent if Waterloo student
4. **Message Generation** → Messages published to `playwright:message` queue
5. **Execution** → Playwright consumes and executes instructions
